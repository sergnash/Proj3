# Парсер новостей Дзена

Собирает заголовки с [dzen.ru/news](https://dzen.ru/news), разбирает HTML через
BeautifulSoup и сохраняет результат в CSV.

## Структура проекта

```
ParseYa/
├── main.py                 # точка входа: python main.py
├── requirements.txt        # зависимости
├── yanews/                 # пакет
│   ├── __init__.py         # публичный API
│   ├── config.py           # URL, заголовки, пути по умолчанию
│   ├── fetcher.py          # загрузка HTML, обход антибот-редиректа
│   ├── parser.py           # NewsItem и разбор разметки
│   ├── exporter.py         # запись CSV
│   └── cli.py              # разбор аргументов командной строки
├── tests/
│   └── test_parser.py      # тесты разбора и CSV (без сети)
└── output/news.csv         # результат
```

Слои разделены: `fetcher` ничего не знает о разметке, `parser` — о сети,
`exporter` — о том, откуда взялись данные. Поэтому парсер тестируется на
заранее сохранённом HTML.

## Установка

```bash
python -m venv .venv
.venv/Scripts/activate        # Windows
pip install -r requirements.txt
```

## Запуск

```bash
python main.py                    # → output/news.csv
python main.py -o news_today.csv  # свой путь
python main.py -q                 # без вывода списка в консоль
```

Полезные опции:

| Опция | Назначение |
|---|---|
| `-o, --output` | путь к CSV (по умолчанию `output/news.csv`) |
| `-u, --url` | другой адрес ленты |
| `--timeout` | таймаут HTTP-запроса |
| `--from-html FILE` | разобрать сохранённую страницу вместо запроса в сеть |
| `--save-html FILE` | сохранить полученный HTML для отладки селекторов |
| `-q, --quiet` | не печатать заголовки |

## Формат CSV

Колонки: `title`, `source`, `published`, `url`, `description`.
Файл пишется в `utf-8-sig`, чтобы Excel корректно показывал кириллицу.

## Как это работает

1. **Сессия.** `dzen.ru/news` без куки отдаёт заглушку — короткий HTML с
   редиректом на `sso.passport.yandex.ru`. Поэтому перед лентой открывается
   главная `dzen.ru`, которая выставляет `yandexuid`, `zen_sso_checked` и др.,
   и только потом запрашивается `/news` в той же сессии.
2. **Селекторы по префиксу класса.** Классы в разметке Дзена имеют хеш-суффикс
   (`news-site--card-news__titleLink-2Q`), который меняется при релизах фронта.
   Парсер ищет по стабильному префиксу (`card-news__titleLink`), а не по
   полному имени.
3. **Дедупликация.** Одна новость встречается и в блоке «Главное», и в
   рубриках — повторы отбрасываются по `href`, порядок страницы сохраняется.

## Ограничения

- Часть ленты — компактные карточки блока «Главное»: в их разметке есть только
  заголовок и ссылка, без источника, времени и описания. Для них эти поля в
  CSV остаются пустыми.
- Лента подгружается по мере прокрутки, поэтому в ответе — первый экран
  (~280 новостей), а не весь архив.
- Если сайт вернул антибот-заглушку, `fetcher` сообщит об этом отдельной
  ошибкой. Повторный запуск обычно помогает; при ограничениях по региону
  нужен VPN.
- Разметка может измениться. При пустом результате запустите
  `python main.py --save-html news.html` и проверьте префиксы классов
  в `yanews/parser.py`.
