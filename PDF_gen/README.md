# PDF_gen — генератор PDF из HTML-шаблона

CLI-инструмент: берёт данные из CSV/JSON, подставляет в HTML-шаблон через Jinja2,
рендерит PDF через WeasyPrint и открывает результат в системном просмотрщике.

## Установка

```bash
python -m pip install -r requirements.txt
```

PDF-рендеринг на Windows требует библиотеки Pango/GTK. Скрипт сам ищет её в типичных местах
(GTK3 Runtime, Inkscape, GIMP, LibreOffice). Если не нашёл — укажите папку с
`libpango-1.0-0.dll`:

```bash
set PDFGEN_GTK_DIR=C:\Program Files\GTK3-Runtime Win64\bin
```

macOS: `brew install pango libffi`. Linux: `sudo apt install libpango-1.0-0 libpangoft2-1.0-0`.

Если Pango нет совсем — `--html` сохранит готовый HTML вместо PDF.

## Запуск

```bash
python pdfgen.py
```

Меню показывает файлы данных и шаблоны, даёт выбрать их по номеру, затем выводит список
счетов (по invoice id). Введите номер — PDF появится в `output/` и откроется.

## Ключи

| Ключ | Что делает |
|---|---|
| `--list` | показать данные и шаблоны, ничего не генерируя |
| `--data`, `--template`, `--invoice` | пропустить интерактивный выбор |
| `--all` | сгенерировать документы по всем счетам |
| `--html` | сохранить HTML вместо PDF |
| `--no-open` | не открывать результат |
| `--open-with browser` | открыть в браузере (по умолчанию — системный просмотрщик) |
| `--strict` | ошибка, если шаблон использует поля, которых нет в данных |
| `-d`, `-t`, `-o` | каталоги данных, шаблонов и вывода |

Пример без интерактива:

```bash
python pdfgen.py --data data/invoices.csv --template templates/invoice.html --invoice INV-1001
```

## Структура

```
pdfgen.py            скрипт
requirements.txt     зависимости
data/                сюда кладутся ваши CSV/JSON
templates/           сюда кладутся ваши HTML-шаблоны
output/              сгенерированные документы
examples/            демо-данные и демо-шаблоны
```

Каталоги `data/`, `templates/`, `output/` создаются автоматически при первом запуске, если их
нет. Если `data/` или `templates/` пусты, скрипт подставит содержимое `examples/` и сообщит об
этом — так демо работает сразу после клонирования. Явно указанные `-d`/`-t` отключают подстановку.

## Как устроены данные

* **CSV** — читается pandas (или стандартным `csv`, если pandas нет). Кодировка определяется
  автоматически (UTF-8, cp1251), разделитель тоже (`,` `;` таб, `|`).
* **JSON** — стандартный `json`. Поддерживаются массив объектов, словарь вида `{"id": {...}}`
  и объект с вложенным массивом (`{"invoices": [...]}`).
* **invoice id** — ищется по полю `invoice_id`, `invoice`, `invoice_number`, `id`, `номер` и
  похожим. Если такого нет, берётся первое поле файла.

## Шаблон

Обычный HTML + Jinja2. Доступные переменные:

| Переменная | Содержимое |
|---|---|
| все поля записи | напрямую, например `{{ buyer }}` |
| `invoice_id` | идентификатор счёта |
| `rows` | все записи выбранного счёта (для таблиц, `{% for row in rows %}`) |
| `columns` | список колонок файла данных |
| `generated_at` | дата и время генерации (`datetime`) |
| `source.file` | имя файла-источника |

Фильтры: `{{ value | money }}` — сумма вида `138 000.00`; `{{ value | dash }}` — прочерк для
пустого значения.

Шрифт DejaVu Sans (или Roboto) подключается автоматически, кириллица поддерживается.
Свой шрифт можно положить в `assets/fonts/DejaVuSans.ttf` (и `-Bold.ttf`) — он получит приоритет.
