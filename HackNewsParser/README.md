# HackNewsParser

Консольный проект на Python, который собирает статьи с главной страницы
[The Hacker News](https://thehackernews.com/), переводит заголовки на русский
язык через Codex CLI и сохраняет результат в CSV-файл.

Сторонние Python-библиотеки не используются: загрузка страницы, разбор HTML,
запуск Codex и запись CSV реализованы средствами стандартной библиотеки.

## Возможности

- получение актуальных материалов с главной страницы The Hacker News;
- извлечение заголовка, ссылки на статью и URL изображения;
- пакетный перевод заголовков через Codex CLI;
- CSV с разделителем `;` и кодировкой `utf-8-sig` для Excel;
- выбор пути выходного файла из командной строки.

## Требования

- Python 3.10 или новее;
- доступ к интернету;
- установленный и авторизованный Codex CLI.

Проверка инструментов:

```powershell
python --version
codex --version
```

Если Codex ещё не авторизован:

```powershell
codex login
```


По умолчанию результат записывается в `headlines.csv`. Другой путь можно
передать через `--output` или `-o`:


```powershell

```

## Формат CSV

| Поле | Описание |
| --- | --- |
| `title` | Оригинальный заголовок |
| `title_ru` | Перевод заголовка на русский язык |
| `url` | Полная ссылка на статью |
| `image_url` | Полная ссылка на изображение |

Пример:

```csv
title;title_ru;url;image_url
Example security headline;Пример заголовка о безопасности;https://example.com/article;https://example.com/image.jpg
```

## Как это работает

1. `download_homepage()` загружает HTML с тайм-аутом и браузерным `User-Agent`.
2. `HeadlineParser` находит элементы `h2.home-title`, ссылки и изображения.
3. `request_translations()` отправляет все заголовки в Codex одним запросом.
4. JSON Schema задаёт ожидаемый формат ответа с массивом переводов.
5. `save_to_csv()` записывает итоговые данные с разделителем `;`.

Codex запускается с параметрами `--ephemeral` и `--sandbox read-only`. Временные
файлы схемы и результата удаляются автоматически.

## Возможные ошибки

### Codex CLI не найден

Проверьте `codex --version` в том же терминале и после установки перезапустите
PowerShell. В Windows скрипт ищет как `codex`, так и `codex.cmd`.

### Заголовки не найдены

Вероятно, сайт изменил разметку. Проверьте класс заголовка и обновите условие
`h2.home-title` в `HeadlineParser`.

### Ошибка сети или тайм-аут

Проверьте интернет, прокси и брандмауэр. Тайм-аут загрузки страницы — 20 секунд,
вызова Codex — 180 секунд.

### CSV некорректно открыт в Excel

При ручном импорте выберите кодировку UTF-8 и разделитель «точка с запятой».
Сам файл уже записывается с BOM для совместимости с Excel.
